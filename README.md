# 🛰️ Satellite Command Center Portfolio

A futuristic, space-themed portfolio website with satellite command center UI, featuring radar sweeps, orbital animations, telemetry data panels, and an AI mission operator assistant.

![Status](https://img.shields.io/badge/status-operational-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)
![Pages](https://img.shields.io/badge/pages-20-orange)

## ✨ Features

- 🎨 **Space Command Center Theme** - Futuristic UI with neon accents
- 📡 **Radar Sweep Animations** - Real-time radar visualization
- 🌍 **Orbital Path System** - Animated satellite orbits
- 📊 **Telemetry Data Panels** - Live system metrics display
- 🤖 **AI Mission Operator** - Interactive guide assistant
- 📱 **Fully Responsive** - Works on all devices
- 🚀 **Performance Optimized** - Fast loading, smooth animations
- 🔒 **Security Best Practices** - CSP headers, secure deployment
